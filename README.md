# 🧠 Algorithms Problem Solver (Design & Analysis Project 2026)

A comprehensive Algorithms project developed for the **Design and Analysis of Algorithms course** at Ain Shams University.
This project implements and compares multiple algorithmic paradigms to solve complex computational problems.

---

## 📌 Project Description

This project explores a collection of challenging algorithmic problems, each solved using different approaches such as:

* Divide and Conquer
* Dynamic Programming
* Greedy Algorithms
* Brute Force
* Iterative Improvement

The goal is to analyze, compare, and understand how different algorithmic strategies perform across various problem types.

---

## 🚀 Implemented Tasks

### 🔹 Task 1: Tromino Tiling Problem

* Tile a (2^n \times 2^n) board with one missing square
* Use:

  * Divide & Conquer
  * Brute Force
* Constraint: No adjacent trominoes share the same color 

---

### 🔹 Task 2: Knight’s Tour Problem

* Determine if a knight can visit all squares exactly once
* Analyze for different board sizes
* Implement:

  * Greedy approach
  * Case analysis 

---

### 🔹 Task 3: Tower of Hanoi (4 Pegs)

* Solve using:

  * Divide & Conquer
  * Dynamic Programming
* Analyze minimum number of moves and optimal strategies 

---

### 🔹 Task 4: Knights Swapping Puzzle

* Swap positions of black and white knights on a 3×4 board
* Use iterative improvement to minimize moves 

---

### 🔹 Task 5: Shooter vs Moving Target

* Design a strategy to guarantee hitting a moving target
* Constraint: Target moves after each shot
* Approach: Divide & Conquer 

---

### 🔹 Task 6: Lattice Covering Problem

* Cover all points using minimum number of lines
* Solve using Dynamic Programming 

---

### 🔹 Task 7: Job Scheduling with Deadlines

* Minimize total penalty
* Solve using:

  * Dynamic Programming
  * Brute Force
  * Divide & Conquer 

---

### 🔹 Task 8: Minimum Cut in Graph

* Approximate minimum cut
* Techniques:

  * Iterative Improvement
  * Brute Force 

---

### 🔹 Task 9: Clustering Problem

* Partition points into k clusters
* Implement:

  * Iterative Improvement
  * Divide & Conquer
  * Brute Force 

---

### 🔹 Task 10: Coin Removal Puzzle

* Remove coins based on flipping rules
* Analyze strategies and optimal moves
